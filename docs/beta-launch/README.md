## 1. Executive Summary

This documentation hub contains the complete operational, positioning, recruitment, compliance, and user onboarding resources required to run a controlled Closed Beta for GGs in India. 

GGs connects **Brands**, **Agencies**, and **Content Creators** in a streamlined marketplace for discovery, smart search, direct contact requests, private quotation negotiations (with no public rate cards), and campaign deliverables tracking.

## 3. Strict Operating Guardrails

1. **Safety First:** No external marketing, paid advertising, or tester onboarding is permitted until Stage 8 security, RLS, and migration tests receive final approval.
2. **Zero Fabrication:** Never invent partner logos, user counts, investor backing, or claim directory influencers have pre-registered.
3. **Consent & Privacy:** All outreach must follow direct, opt-in communication standards. Automated scraping or mass unprompted DMing is strictly prohibited.
