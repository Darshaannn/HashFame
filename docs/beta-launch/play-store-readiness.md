# GGs Google Play Beta Preparation & Store Readiness

## 1. Google Play Console Account Overview

Google Play Console enforces specific onboarding and testing rules depending on account type:

| Account Type | Closed Testing Requirements | Key Conditions |
| :--- | :--- | :--- |
| **Personal Developer Account** (created after Nov 2023) | **Mandatory 12 Testers for 14 Consecutive Days** | At least 12 opted-in testers must remain continuously enrolled in a closed test track for 14 days before applying for production access. |
| **Organization Account** (D-U-N-S verified company) | No mandatory 14-day hold, but closed testing track is strongly recommended. | Requires verified D-U-N-S number, corporate documentation, and official email domain. |

*Plan Assumption:* Prepare for the stringent **12-tester / 14-day continuous opt-in requirement**.

---

## 2. Technical Build & Package Requirements

- **Package Name / Application ID:** `com.ggs.mobile.staging` (for closed testing) and `com.ggs.mobile.production` (for release).
- **Format:** Android App Bundle (`.aab`) signed with release keystore.
- **Target SDK:** Android 14 (API level 34) or higher (Complied in GGs configuration).
- **Minimum SDK:** Android 6.0 (API level 23).
- **Architectures:** `arm64-v8a`, `armeabi-v7a`, `x86_64`.
- **Permissions:** `android.permission.INTERNET` (No invasive permissions like camera, background location, or contacts are requested).

## 3. Store Listing Assets & Copy Specification

### 3.1 Metadata
- **App Title:** `GGs: Creator Collaboration` (Max 30 characters)
- **Short Description:** `Connect with Indian creators. Intelligent discovery & private quotations.` (Max 80 characters)
- **Full Description:**  
  *GGs is India's creator collaboration marketplace connecting brands, agencies, and content creators. Discover verified talent across Mumbai, Delhi NCR, and all major cities. Say goodbye to public rate cards—negotiate private, custom quotations tailored to your exact campaign deliverables.*

### 3.2 Visual Graphic Assets
- **App Icon:** 512 x 512 px, 32-bit PNG with alpha channel.
- **Feature Graphic:** 1024 x 500 px, JPG or 24-bit PNG (No alpha). Featuring Deep Burgundy `#8B0000` branding.
- **Phone Screenshots:** Minimum 4 screenshots (1080 x 2400 px or 16:9 ratio):
  1. *Screen 1:* Natural Language Creator Search (Intelligent discovery)
  2. *Screen 2:* Creator Profile & Verified Meta Grid (Authentic reach)
  3. *Screen 3:* Private Quotation Request (No public rate cards)
  4. *Screen 4:* Campaign Workspace & Deliverables Tracking

## 4. Data Safety Declarations

In the Google Play Console Data Safety form, declare:
- **Data Collected:**
  - *Personal Info:* Name, Email Address, Phone Number (optional for creator direct contact).
  - *App Activity:* Search interactions, shortlist creation (for in-app performance).
  - *Identifiers:* User ID generated by Supabase Auth.
- **Data Security:**
  - All data is encrypted in transit using HTTPS (TLS 1.3).
  - Users can request account and data deletion via an in-app option or web URL.
- **Third-Party Data Sharing:**
  - No user data is sold to third parties.

---

## 5. Closed Testing Track Setup Steps

1. Create a Closed Testing Track titled **"Beta Testers Cohort 1"**.
2. Create an Email List containing 20–30 approved tester Google Accounts.
3. Upload the signed `app-staging-release.aab` bundle.
4. Copy the **Web Opt-in Link** and **Android Play Store Link**.
5. Distribute opt-in links to the enrolled creator and brand testers.
6. Verify daily active test engagement across the 14-day window.
